# 一起开画：你画我猜多人在线版

这是一个简体中文界面的实时多人你画我猜网页小游戏。前端使用 HTML/CSS/JavaScript，服务端使用 Node.js、Express 和 Socket.IO。

## 游戏功能

- 创建房间，自动生成 5 位邀请码
- 复制邀请链接，好友打开链接后输入昵称即可加入
- 最多 12 位玩家实时同步画板
- 房主开始游戏，每轮随机选词并轮流作画
- 猜词聊天室、答对得分、倒计时和积分排行榜
- 画笔颜色、粗细、橡皮擦、清空画板
- 适配电脑和手机浏览器

## 本地运行

需要安装 Node.js 18 或更高版本。

```bash
npm install
npm start
```

浏览器打开 http://localhost:3000。

## 局域网联机

启动服务器后，朋友可以访问运行服务器的电脑在局域网内的 IP 地址，例如 `http://192.168.1.20:3000`。确保设备连接同一网络，并且电脑防火墙允许访问对应端口。

## 异地公网联机

要让不同城市的朋友一起玩，需要将项目部署到支持 Node.js、WebSocket/长轮询的公网服务平台：

1. 将项目上传到 Git 仓库。
2. 在支持 Node.js 的托管平台创建 Web Service。
3. 安装命令设置为 `npm install`，启动命令设置为 `npm start`。
4. 部署成功后，将平台提供的 HTTPS 地址发给朋友。

## 当前版本说明

房间和分数保存在服务器进程内存中，服务器重启后房间会清空。当前版本适合朋友娱乐和原型体验，尚未加入账号系统、持久化数据库、语音、反作弊和内容审核。
